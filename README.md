# Smart Medicine Safety

## Project Description

Smart Medicine Safety is a patient-focused digital healthcare application designed to help users understand their medicines and identify potential drug interactions before taking them.

The application allows users to search for medicines using their brand name, generic name, strength, or common medicine names. Users can add medicines to their personal medication list and review potential interactions between selected medicines.

The platform is designed with a simple and user-friendly interface so that patients and families can easily access medicine safety information.

## Key Features

- Search medicines by brand or generic name
- View medicine strength and medicine type
- Add medicines to a personal active medication list
- Remove individual medicines or clear the entire list
- Drug interaction analysis
- Severe interaction warnings
- Moderate interaction warnings
- General medicine safety information
- Medicine expiry and safety awareness
- User registration and login interface
- Responsive design for desktop and mobile devices
- Patient-friendly healthcare interface

## Drug Interaction Examples

The project demonstrates medicine safety checks using examples such as:

- Omeprazole + Clopidogrel: Potential reduction in the effectiveness of Clopidogrel
- Lisinopril + Ibuprofen: Potential increased risk of kidney problems and effects on blood pressure

These examples are displayed to demonstrate how a medicine interaction warning system can present potential safety concerns to users.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase for authentication and database integration

## Project Purpose

The purpose of this project is to create a digital medicine safety platform that makes medicine-related information easier to access and understand.

Users can build a list of medicines they are taking and use the application as a tool to review potential medicine interactions and safety-related information.

The application is intended for educational purposes and is not a replacement for professional medical advice. Users should always consult a qualified doctor, pharmacist, or healthcare professional before making decisions about their medications.
